<h1 align="center">
 dmg builder
</h1>

<p align="center">
dmg builder is a Python-powered tool that converts .app files to .dmg files.
</p>

<p align="center">
<a href="README-en.md">中文</a> | English
</p>

## Usage:
- Click the first "Browse..." button to select your .app file.
- Click the second "Browse..." button to choose the save location for the output .dmg file. If no path is selected, the .dmg file will be saved in the same directory as the source .app file.
- Enter the disk volume name.
- Click "Start Packaging". A pop-up window will appear once the packaging process is completed successfully, which means you have finished the whole packaging operation.
